Handle this page like a Wi-Fi password card — the code contains the network password.

1 Power on a factory-fresh terminal

The device must be brand-new or freshly factory-reset, with no accounts added. Keep it plugged in.

Before you scan: the FLO Secure Wi-Fi network must be up, in range of the terminal, and using the standard FLO password. The terminal joins it automatically during setup — if it isn't there, setup stops with "Couldn't set up your device" and you'll need to factory-reset and start over. Check that a phone can join FLO Secure first.

2 Tap the welcome screen 6 times

On the very first setup-wizard screen, tap the same spot six times. A QR scanner opens. (If it offers to connect Wi-Fi or fetch a scanner first, allow it.)

3 Scan the code above

The terminal joins FLO Secure, downloads and installs the launcher, and takes over device management automatically. This download is the longest wait.

4 Watch the black setup screen

Five checks run on their own: default home, hide taskbar, save Wi-Fi, keep screen on, verify apps. Don't power off while they run.

5 Done — Chrome & Settings home

The terminal lands on the black home screen with Chrome and Settings. Long-press anywhere for the PIN-protected admin panel.

If something goes wrong

  • "Couldn't set up your device": most often the terminal couldn't join FLO Secure (network down, out of range, or wrong password), or the terminal wasn't account-free. Fix the network, factory-reset, and scan again.
  • Download stalls: check the shop Wi-Fi. The setup screen shows a retry; restore Wi-Fi and tap Retry.
  • A taskbar or app is still installed: long-press home → PIN → View provisioning log, and note what it says. See the OEM caveats in the project docs.
